# ⚡ Monster Energy Interactive Carousel

![Preview do Projeto](./preview.png)

Uma aplicação interativa desenvolvida com **React + Vite**, simulando uma apresentação dinâmica de produtos da Monster Energy.

O projeto foca em:
- Animações suaves
- Transições entre estados
- Manipulação de imagens
- Organização profissional de assets
- Deploy no GitHub Pages

---

## 🚀 Demonstração

🔗 Acesse online:  
https://caua-ricken.github.io/Monster-Page/

---

## 🧠 Sobre o Projeto

Essa aplicação foi criada com o objetivo de praticar:

- Gerenciamento de estado com `useState`
- Manipulação de index para carrossel infinito
- Lógica de next/prev
- Organização de imagens em `/assets`
- Correção de paths para produção
- Deploy com `gh-pages`

---

## 🛠️ Tecnologias Utilizadas

- React
- Vite
- JavaScript
- CSS3
- GitHub Pages
- gh-pages

---

## ✨ Funcionalidades

- 🔄 Carrossel com navegação Next e Prev
- 🎨 Mudança dinâmica de background
- 🖼️ Troca animada de imagens
- 📍 Indicadores de posição (barras inferiores)
- ♾️ Loop infinito no carrossel
- 🚀 Build otimizado para produção
